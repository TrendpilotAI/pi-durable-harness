In the current working directory, build a tiny Python package for interval arithmetic.

Deliverables:
1) intervals.py with a function merge_intervals(intervals) that takes a list of [start, end] pairs (ints, start <= end, any order, possibly empty) and returns a new sorted list of merged, non-overlapping [start, end] pairs. Touching intervals such as [1, 2] and [2, 3] merge into [1, 3]. Raise ValueError for a pair whose start > end.
2) test_intervals.py using only the standard-library unittest module, with at least 6 test cases covering empty input, unsorted input, nested intervals, touching intervals, a single interval, and the ValueError case.
3) NOTES.md with three short lines: the algorithm, its time complexity, and the command that runs the tests.

Run `python3 -m unittest -q` and make sure it passes before you finish. Do not use network access or third-party packages.
